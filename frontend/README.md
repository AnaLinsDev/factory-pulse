# 🚀 Real-Time Shopfloor Dashboard (Frontend)

A **real-time industrial simulation APP** built with **NextJs, Tailwind, Jest (Tests), Eslint, TypeScript, and Socket.IO**, designed to mimic a shopfloor environment with machines, production orders, and live metrics.

---


### 📡 Socket events **live updates**

* `machine:update`
* `order:update`
* `metrics:update`

---

# 🌐 Screens 

| Screen        | Description                                |
| ------        | ---------------------                      |
| Dashboard     | Dashboard orders, machines and metrics     |
| Order         | List all orders                            |
| Machines      | List all machines                          |
    
---

# 🚀 How to run the project

## 📦 1. Install dependencies

```
npm install
```

---

## ⚙️ 2. Create `.env.local` file

```
NEXT_PUBLIC_API_URL=http://localhost:3000
```

---

## 🧪 3. Run in development

```
npm run dev
```

---

## 🏗 4. Build project

```
npm run build
```

---

## ▶️ 5. Run production

```
npm start
```

---
## ▶️ 6. Run tests

```
npm run test
```

---
## ▶️ 6. Run eslint

```
npm run lint
```
